# Skill-Track: Track trainee journey beyond training

## summery:
- Consent based trainee tracking.
- Track trainee performance while at the training & after they finish training.
- Shows trainee employeement status, current organization, salary groth, position in based on consent.
- Provides skill gap analysis, based on their current skill set and the current skill demand for role they aiming for.
- Automatic follow up emails in every 3 months.
- Lists course provivers and they courses they offer.
- Gives suggestions to course providers based on current market demand.

## Challanges:
- Collect data reliably and regularly from trainees (current and past).
- Verify the data given by trainees.
- Keeping up with the latest information with the job market.

## AI intigration:
- Skill gap analysis.
- "Work on these skills" recommendations.
- Course work improvement recommendations to course providers.
